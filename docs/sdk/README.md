# SDK and CLI

The stable developer surface is split across private local packages:

- `@tts-research/schema` for JSON schemas, generated TypeScript types, and validators;
- `@tts-research/sdk-ts` for the thin API client and reusable Content IR, locator, speech-plan, highlight-map, and timing helpers;
- `@tts-research/cli` for `voice-studio`;
- `voice-studio-sdk` for the optional thin Python schema/client package.

See the Node, browser, CLI, Python, and packaging notes in this directory.
